# RFC 0022 — Transaction Structure Notes

**Date:** August 4, 2026

## Transaction Fields

###cell_deps -
 Cells referenced as read-only dependencies 

###header_deps -
 Block headers the transaction depends on

###Inputs -
 Cells being consumed (destroyed)

###outputs -
 New cells being created

###outputs_data -
 Data field for each output cell

###witnesses -
 Proofs/Signatures (not sored on-chain in cells )
